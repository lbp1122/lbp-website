FREE HOSTING WITH GITHUB PAGES
1. Create or sign in to a GitHub account.
2. Create a new public repository, e.g. lbpconsolidated.
3. Upload all files and the assets folder to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and / (root), then Save.
7. GitHub will show your free website address after deployment.

You may later connect a custom domain if desired.
